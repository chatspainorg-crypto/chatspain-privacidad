Política de privacidad de CHATSpain

Última actualización: 14 de octubre de 2026

1. Responsable y contacto

CHATSpain es una aplicación que permite conectarse a una red de chat IRC. Para consultas sobre privacidad, puedes escribir a: chatspain.org@gmail.com.

2. Datos tratados

Para proporcionar el servicio, la aplicación y el servidor pueden tratar datos técnicos necesarios para establecer y mantener la conexión, como el nick elegido, la dirección del servidor, las salas a las que se accede y los mensajes que el usuario decide enviar.

El servicio IRC puede procesar direcciones IP y otros datos técnicos de conexión para gestionar las conexiones, prevenir abusos y mantener la seguridad.

3. Mensajes y salas públicas

Los mensajes enviados a salas públicas pueden ser visibles para otras personas conectadas a dichas salas. No compartas información personal que no quieras hacer pública.

Los mensajes privados se transmiten a sus destinatarios a través del servicio IRC. No deben considerarse un canal cifrado de extremo a extremo.

4. Finalidades

Los datos técnicos se utilizan para prestar el servicio de chat, gestionar las conexiones, mantener la seguridad, solucionar incidencias y prevenir usos abusivos.

5. Registros técnicos y conservación

El servidor puede generar registros técnicos y de seguridad que incluyan datos de conexión. El periodo de conservación depende de la configuración y de las necesidades de seguridad del servicio. No se establece aquí un plazo concreto hasta que haya sido verificado.

6. Comunicación de datos

Los datos se procesan en la medida necesaria para operar el servicio IRC. No se afirma que exista una cesión comercial de datos. Podrán comunicarse cuando exista una obligación legal válida o sea necesario para atender incidentes de seguridad conforme a la normativa aplicable.

7. Seguridad

La conexión al servidor IRC se configura mediante TLS. Esto protege el transporte de los datos entre el cliente y el servidor, pero no significa que los mensajes estén cifrados de extremo a extremo.

8. Derechos de las personas usuarias

Según la normativa aplicable, puedes solicitar acceso, rectificación, supresión, limitación u oponerte al tratamiento de tus datos, así como ejercer otros derechos que correspondan, escribiendo a chatspain.org@gmail.com.

También puedes presentar una reclamación ante la Agencia Española de Protección de Datos: www.aepd.es.

9. Menores

La aplicación no debe utilizarse de forma contraria a los requisitos de edad, las condiciones del servicio o la legislación aplicable. Las personas responsables de menores deben supervisar su uso cuando corresponda.

10. Cambios en esta política

Esta política podrá actualizarse para reflejar cambios en la aplicación, el servidor o los requisitos legales. La versión vigente estará disponible en esta página.

Contacto de privacidad: chatspain.org@gmail.com
